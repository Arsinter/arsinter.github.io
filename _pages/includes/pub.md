# 📝Publications and Projects

**EduAgentVerse** (2024.11 - 2025.03)  
Multi-Agent Metaverse English Learning Platform · Sangfor Cup (Team) (Advisor: Prof. Xiao Wang)

- Designed overall framework using *AutoGen* as multi-agent system, constructing four-layer architecture of "scenario, agent, data, interaction";
- Developed English proficiency evaluation: agents generate reference answers using *Student Answer Forecasting*, using *Lexile scores* as dialogue difficulty metric, comparing user answers with references via *BLEURT* metric for similarity assessment to adjust text readability;
- Implemented immersive English practice in metaverse environment with real-time user interaction and dialogue generation with NPCs.
